# Tujuan:
Ubah desain portofolio web menjadi antarmuka "Modern Minimalist" (Index-based) yang sangat bersih, terinspirasi dari mschristensen.com, dilengkapi interaksi kursor inversi.

# Arsitektur & Estetika Visual (HTML/CSS):
1. **Struktur Tata Letak:** Gunakan pendekatan tanpa garis tepi (*borderless*). Jangan gunakan `border` pada daftar indeks proyek. Terapkan sistem grid yang kaku dan manfaatkan ruang kosong (*whitespace*) yang terukur untuk memisahkan informasi.
2. **Skema Warna Spesifik:**
   - Latar Belakang: Dark Slate/Greenish pekat (contoh: `#0C1412` atau serupa).
   - Teks Utama: Off-White (contoh: `#F0F0F0`).
   - Kursor Kustom & Elemen Aktif: Pale Green (contoh: `#BCE4A3`).
3. **Tipografi:** Gunakan font Sans-Serif yang bersih dan teknis (seperti Inter atau Satoshi).

# Interaksi Kursor Lanjutan (JavaScript & CSS):
1. Sembunyikan kursor bawaan peramban (`cursor: none`).
2. Buat kursor kustom beserta ekornya (*trail*) menggunakan elemen berwarna Pale Green (`#BCE4A3`). Gunakan JavaScript dengan fungsi interpolasi linier (*Lerp*) agar pergerakan ekornya sangat mulus, elastis, dan merespons pergerakan mouse tanpa patah-patah.
3. Terapkan properti CSS `mix-blend-mode: difference` pada kursor/ekor tersebut. Pastikan saat kursor Pale Green melintasi teks Off-White, kalkulasi matematis peramban menghasilkan warna inversi yang tajam, persis seperti efek pada gambar referensi.
